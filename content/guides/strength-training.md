## 为什么跑者需要力量训练

马拉松后半程掉速，很多时候不是心肺不够，而是**肌肉耐力撑不住跑姿**：
骨盆下沉、步幅变小、着地变重。力量训练可以：

- 提高跑步经济性（同样配速消耗更少能量）
- 减少膝盖、髂胫束、跟腱等常见伤病
- 让 30km 之后的跑姿依然稳定

## 需要的用具

| 用具               | 用途                           | 必要度 |
| ------------------ | ------------------------------ | ------ |
| 瑜伽垫             | 臀桥、平板支撑、死虫、鸟狗     | 必备   |
| 长凳 / 稳固的椅子  | 保加利亚分腿蹲                 | 推荐   |
| 台阶               | 提踵（让脚跟落到台阶以下）     | 推荐   |
| 迷你弹力带（环形） | 弹力带侧走，激活臀中肌         | 推荐   |
| 哑铃 / 壶铃        | 深蹲、罗马尼亚硬拉、提踵加负重 | 进阶   |
| 跳绳 / 跳箱        | 增强弹性和着地刚度             | 进阶   |

在家只用自重和一张瑜伽垫就能完成基础计划。各用具的选法见 [装备与用具](/guides/gear/)。

## 每周安排

- **每周 2 次**，放在轻松跑当天或休息日
- 不要放在间歇、长距离的前一天
- 减量期（比赛前 2〜3 周）减少组数，比赛前一周停止大重量训练

## 基础计划（自重即可）

每个动作 3 组，组间休息 45〜60 秒。

### 下肢

| 动作                                                                               | 次数         | 目标                   |
| ---------------------------------------------------------------------------------- | ------------ | ---------------------- |
| [深蹲](/exercises/squat/)                                                          | 15 次        | 股四头肌、臀部         |
| [保加利亚分腿蹲](/exercises/split-squat/)                                          | 左右各 10 次 | 单腿稳定、臀部         |
| [单腿臀桥](/exercises/single-leg-bridge/)                                          | 左右各 12 次 | 臀大肌、腘绳肌         |
| [单腿提踵](/exercises/calf-raise/)                                                 | 左右各 15 次 | 小腿、跟腱             |
| [侧卧抬腿](/exercises/side-lying-leg-raise/) / [弹力带侧走](/exercises/band-walk/) | 左右各 15 次 | 臀中肌（防止膝盖内扣） |

### 核心

| 动作                                 | 时间 / 次数      | 目标             |
| ------------------------------------ | ---------------- | ---------------- |
| [平板支撑](/exercises/plank/)        | 45〜60 秒        | 腹横肌、整体稳定 |
| [侧平板支撑](/exercises/side-plank/) | 左右各 30〜45 秒 | 腹斜肌、骨盆稳定 |
| [死虫](/exercises/dead-bug/)         | 左右各 10 次     | 抗伸展、协调     |
| [鸟狗](/exercises/bird-dog/)         | 左右各 10 次     | 下背部、臀部     |

### 进阶（有器械时）

- [罗马尼亚硬拉](/exercises/romanian-deadlift/)：8〜10 次 × 3 组，强化后链
- [负重提踵](/exercises/weighted-calf-raise/)：12 次 × 3 组
- [跳箱](/exercises/box-jump/) / [跳绳](/exercises/jump-rope/)：增强弹性和着地刚度，每周 1 次即可

## 要点

- **动作质量优先于次数**，膝盖与脚尖方向一致，核心收紧
- 循序渐进：动作轻松完成 3 组后，再增加次数或负重
- 训练后第二天的跑步以轻松跑为主
