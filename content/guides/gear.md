> 破四不靠装备，但合适的装备能减少伤病、让训练更顺利。先把**跑鞋、袜子、手表**配好，其余按需添置。

## 跑鞋

跑鞋是唯一不能省的装备。建议至少准备两双轮换。

| 类型          | 用途                     | 选择要点                                                                         |
| ------------- | ------------------------ | -------------------------------------------------------------------------------- |
| 日常训练鞋    | 轻松跑、LSD、恢复跑      | 缓震充足、耐用、脚感舒适                                                         |
| 节奏 / 竞速鞋 | 马拉松配速跑、间歇、比赛 | 更轻、回弹好；破四跑者选**带缓震的碳板鞋或尼龙板鞋**即可，不必追求最激进的竞速款 |

- **试穿在下午或跑步后**，脚会比早上大半码；鞋头留约一指宽
- 比赛鞋要提前用 25km 以上的长距离试穿，**不要在比赛日穿新鞋**
- 寿命约 **600〜800km**；中底明显变硬、鞋底磨平时更换
- 两双以上轮换穿，中底有时间回弹，也能减少同一部位的重复负荷

## 袜子与服装

| 装备          | 选择要点                                     |
| ------------- | -------------------------------------------- |
| 跑步袜        | 速干、无缝、贴合；五指袜可以减少脚趾间水泡   |
| 上衣          | 速干面料，不选棉质（吸汗后变重、磨皮肤）     |
| 短裤 / 紧身裤 | 带内衬的短裤；大腿内侧容易磨的人可选紧身短裤 |
| 冬季          | 分层穿：速干内层 + 薄外套；手套、帽子、护耳  |
| 夏季          | 遮阳帽、墨镜、浅色衣服                       |
| 夜跑          | 反光背心、头灯或臂灯                         |

## 手表与心率

| 装备         | 用途                                                            |
| ------------ | --------------------------------------------------------------- |
| GPS 运动手表 | 配速、距离、心率区间、训练负荷；续航至少能覆盖 5 小时以上的全马 |
| 胸带心率带   | 间歇等心率变化快的训练比手腕光学心率更准                        |

- 用手表设置 **5'40"/km 的配速提醒**，在马拉松配速跑中练习稳定配速
- 关注晨起静息心率和 HRV 的变化，判断恢复状态（见 [恢复与伤病预防](/guides/recovery/)）

## 补给与携带

| 装备            | 说明                                                        |
| --------------- | ----------------------------------------------------------- |
| 能量胶          | 每个约 20〜30g 碳水；全马准备 4〜5 个，长距离训练中提前试吃 |
| 盐丸 / 电解质片 | 25km、35km 前后补充，预防抽筋                               |
| 腰包 / 跑步腰带 | 装能量胶、手机、钥匙，跑动中不晃                            |
| 水壶 / 软水壶   | 夏季长距离训练时随身补水                                    |
| 防磨膏 / 凡士林 | 涂在腋下、大腿内侧、脚趾等容易磨的部位                      |
| 乳头贴          | 长距离时防止衣服摩擦出血                                    |

## 训练辅助用具

这些用具价格不高，能让热身、拉伸、力量训练和恢复事半功倍。

| 用具               | 用途                                                   | 推荐场景                                                                                                                    |
| ------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 瑜伽垫             | 力量训练、拉伸的基础，厚度 6〜10mm 为宜                | [臀桥](/exercises/glute-bridge/)、[平板支撑](/exercises/plank/)、[死虫](/exercises/dead-bug/)、[鸟狗](/exercises/bird-dog/) |
| 泡沫轴             | 大面积放松小腿、大腿、臀部；新手选中等硬度、表面平滑的 | 跑后放松、恢复日                                                                                                            |
| 筋膜球 / 按摩球    | 足底、臀部、小腿等小范围的痛点                         | 足底筋膜放松                                                                                                                |
| 迷你弹力带（环形） | 弹力带侧走、蚌式开合，激活臀中肌，防止膝盖内扣         | 跑前激活、力量训练                                                                                                          |
| 长弹力带           | 辅助拉伸大腿后侧，或做阻力训练                         | [大腿后侧拉伸](/exercises/hamstring-stretch/)                                                                               |
| 长凳 / 稳固的椅子  | 后脚搭在上面做单腿蹲                                   | [保加利亚分腿蹲](/exercises/split-squat/)                                                                                   |
| 台阶               | 让脚跟落到台阶以下，扩大活动范围                       | [单腿提踵](/exercises/calf-raise/)                                                                                          |
| 哑铃 / 壶铃        | 给深蹲、硬拉、提踵加负重                               | [负重提踵](/exercises/weighted-calf-raise/)、[罗马尼亚硬拉](/exercises/romanian-deadlift/)                                  |
| 跳绳               | 增强脚踝弹性和着地刚度                                 | [跳绳](/exercises/jump-rope/)，每周 1 次，5〜10 分钟                                                                        |

## 比赛日清单

| 类别   | 物品                                       |
| ------ | ------------------------------------------ |
| 必带   | 号码布、别针 / 号码带、计时芯片、身份证件  |
| 穿着   | 试穿过的比赛鞋和袜子、比赛服、帽子、墨镜   |
| 补给   | 能量胶 4〜5 个、盐丸、起跑前的早餐与能量胶 |
| 防护   | 防磨膏、乳头贴、防晒霜                     |
| 起跑前 | 一次性雨衣或旧衣服（保暖，起跑前丢弃）     |
| 赛后   | 换洗衣物、毛巾、保暖外套、拖鞋             |
