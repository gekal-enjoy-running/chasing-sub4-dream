## 需要的用具

| 用具                      | 用途                                      |
| ------------------------- | ----------------------------------------- |
| 运动手表 / 心率带         | 记录晨起静息心率、HRV、睡眠，判断恢复状态 |
| 泡沫轴、筋膜球            | 训练后放松肌肉                            |
| 跑步日志（手表 App 即可） | 记录周跑量，控制增幅                      |
| 补给（能量胶、电解质）    | 长距离训练中补充能量和盐分                |

## 恢复的三要素

### 1. 睡眠

- 每晚 **7〜9 小时**，高强度训练期尽量更多
- 晨起静息心率比平时高 5 次/分钟以上，说明恢复不足，当天改成轻松跑或休息

### 2. 营养

- 训练后 30〜60 分钟内补充**碳水 + 蛋白质**（例：香蕉 + 牛奶、饭团 + 鸡蛋）
- 长距离之前一天晚餐以碳水为主
- 跑步中 60 分钟以上需要补充能量和电解质

### 3. 跑量控制

- 周跑量增加**不超过 10%**
- 每 3〜4 周安排一个**减量周**（跑量降低 20〜30%）
- 轻松跑一定要真的轻松：能边跑边说话

## 常见伤病信号

| 部位         | 常见问题     | 预防                             |
| ------------ | ------------ | -------------------------------- |
| 膝盖外侧     | 髂胫束综合征 | 臀中肌力量、泡沫轴放松大腿外侧   |
| 膝盖前侧     | 髌股疼痛     | 股四头肌和臀部力量、避免突然加量 |
| 脚跟 / 足底  | 足底筋膜炎   | 小腿拉伸、及时更换跑鞋           |
| 跟腱         | 跟腱炎       | 离心提踵、控制坡道和速度课的量   |
| 小腿胫骨内侧 | 胫骨疼痛     | 循序加量、软地面训练             |

**疼痛影响跑姿、或休息 2〜3 天仍未减轻，请停止训练并就医。**

> 本页内容为一般性训练参考，不构成医疗建议。
