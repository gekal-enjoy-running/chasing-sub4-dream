equipment: [泡沫轴, 瑜伽垫]

## 动作步骤（以小腿为例）

1. 坐在垫子上，把小腿放在泡沫轴上，双手在身后撑地
2. 抬起臀部，用手推动身体前后移动，让泡沫轴从跟腱上方滚到膝盖下方
3. 遇到特别紧的点停留 20〜30 秒
4. 把一条腿叠在另一条腿上可以增加压力

## 其他部位

| 部位     | 姿势                                                       |
| -------- | ---------------------------------------------------------- |
| 大腿前侧 | 俯卧，前臂撑地，泡沫轴在大腿前侧                           |
| 大腿后侧 | 坐姿，泡沫轴在大腿后侧，双手撑地                           |
| 臀部     | 坐在泡沫轴上，一侧脚踝搭在另一侧膝盖上，身体向搭腿一侧倾斜 |
| 大腿外侧 | 侧卧，泡沫轴在大腿外侧，上方腿踩在前方地面分担体重         |

## 要点

- 慢慢滚，每秒约 2〜3cm
- 疼痛控制在“痛但舒服”的程度

## 常见错误

- 直接压在膝盖、骨头或关节上
- 滚得太快，只是在“擀面”
